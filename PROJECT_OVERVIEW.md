# Haunted House Escape — Project Overview

First-person horror escape prototype. Unity 6.3 project with a greybox house, a hunting AI enemy,
4 collectible pages, a key and a locked front door. Almost all content is generated by editor
"builder" scripts (`Haunted House` menu); the localisation folders and asset pack are secondary.

## 1. Engine, render pipeline, packages

- **Unity:** `6000.3.10f1` (Unity 6.3), revision `e35f0c77bd8e`.
- **Render pipeline:** URP. `Packages/manifest.json` has `com.unity.render-pipelines.universal 17.3.0`;
  `GraphicsSettings.asset` sets a custom SRP asset = `Assets/Settings/PC_RPAsset.asset`
  (GUID `4b83569d…`); `QualitySettings` levels also reference `Mobile_RPAsset`. Global settings:
  `Assets/Settings/UniversalRenderPipelineGlobalSettings.asset`; default volume profile in `Assets/Settings`.
- **Packages (explicit):** `com.unity.ai.navigation 2.0.10`, `com.unity.collab-proxy 2.11.3`,
  `com.unity.ide.rider 3.0.39`, `com.unity.ide.visualstudio 2.0.26`, `com.unity.inputsystem 1.18.0`,
  `com.unity.multiplayer.center 1.0.1`, `com.unity.probuilder 6.0.9`,
  `com.unity.render-pipelines.universal 17.3.0`, `com.unity.test-framework 1.6.0`,
  `com.unity.timeline 1.8.10`, `com.unity.ugui 2.0.0`, `com.unity.visualscripting 1.9.9`,
  plus 34 built-in `com.unity.modules.*` (ai, animation, audio, particlesystem, physics, terrain, ui, …).
- Product name: "Haunted House Escape"; colour space linear; `activeInputHandler: 2` (old + new input).

## 5. Layers, tags, sorting layers

- **Tags:** none defined (`tags: []`); only the built-in ones are used (`MainCamera` on the camera).
- **Layers (index):** 0 Default, 1 TransparentFX, 2 Ignore Raycast, 3 *(empty)*, 4 Water, 5 UI, 6 **Obstacle**,
  7–31 empty. Gameplay uses UI=5 for canvas, Obstacle=6 for walls/barricades (the enemy's line-of-sight mask is `1<<6`).
- **Sorting layers:** only `Default`.
- **Rendering layers:** Default + Light Layer 1–7 (URP defaults, unused by the game).

## 6. Game rules as implemented

- **Pages:** `PageSpawner` spawns 4 pages (`pagesToSpawn`) on 4 random distinct spots from 9 candidates.
  Interacting (`Page.cs`) calls `GameManager.CollectPage`: counter++, `enemy.Enrage(pages)`, enables
  `barricades[pages-1]` ("the house changes"), updates `Pages: n/4`, shows a hint. At 4/4 the key is spawned
  at one random of 4 key spots.
- **Key:** `KeyItem` sets `HasKey`. `ExitDoor.Prompt` becomes "Unlock and escape"; interacting wins, otherwise
  it only hints that the door is locked.
- **Winning / losing:** `GameManager.Win/Lose` show WinPanel/LosePanel once, set `Time.timeScale = 0`, unlock the
  cursor. Restart button → reload active scene; MenuButton → MainMenu. Losing happens in `EnemyAI.Update` when
  the flat distance to an unhidden player drops under `catchDistance` (serialized 1.3 m).
- **Enemy states:** `Patrol → Idle (look left/right) → Investigate → Search → Chase`. Senses: sight cone
  (`sightRange` 12 m, `sightAngle` 100°) with a raycast on `obstacleMask`; hearing when the player's
  `CurrentNoise` radius reaches her. Chase keeps the last known position, `loseSightTime` 3 s then a 6 s
  search around it. `startDelay` 8 s gives the player a head start; stuck timer re-picks a waypoint;
  `huntChance` (+0.1/page) biases patrol targets toward the player. `Enrage` adds `speedPerPage` 0.35 to chase
  speed per page.
- **Noise:** `PlayerController` publishes a radius: 0 idle, 2 crouch, 6 walk, 14 run. `NoiseOnImpact` on a
  thrown bottle plays `shatter`, calls `HearNoise` (investigate, ignored while chasing) and destroys itself.
- **Hiding:** three lockers. Interacting teleports the player onto `hidePoint`, disables the CharacterController
  while moving, sets `IsHidden`/`CanMove=false`; the enemy ignores a hidden player for sight, hearing and
  catching. Interacting again teleports to `exitPoint`.
- **Flashlight:** starts off, `F` toggles, 100 battery, drains 2/s, flickers under 15 %, dies at 0.
  Batteries (`ItemPickup` type Battery) add 40.
- **Audio/atmosphere:** 3D hum loop on the enemy, 2D ambience; footsteps rate/volume follow noise level;
  heartbeat volume/pitch rise as the enemy nears; chase music fades in while chasing, sting on chase start;
  9 lamps flicker within 9 m of the enemy.
- **In code but not actually in the scene:** `Page`/`KeyItem`/`NoiseOnImpact` only exist inside prefabs,
  so no page or key instance is in `House.unity`; `PackProps` (asset-pack furniture) is empty and
  `ExitDoorModel` has no children, so the `APPLY ASSET PACK` step appears never to have been run on the
  saved scene. The `EnemyAI` wander fields (`idleTime`, `lookAngle`, `lookSpeed`, `huntChance`,
  `huntChancePerPage`, `searchRadius`, `stuckTime`) are absent from the serialized scene — it was saved
  before those fields existed, so they run on their script defaults.

## 7. Looks broken / unfinished

- **`EnemyAI1.cs` contains `class EnemyAI`** — file name ≠ class name; the Inspector cannot attach it by
  name and `AddComponent<EnemyAI>` tooling is fragile (the scene still works because the script reference is
  by GUID).
- **Editor scripts live in `Assets/Scripts`**: `BuildEnemy`, `BuildGreyboxHouse`, `BuildPhase7`, `BuildPhase8`,
  `BuildSpawnSpots`, `FinishGame` all `using UnityEditor` from `Assembly-CSharp`, which will fail a player
  build. `FinishGame.cs`'s own header says to place it in `Assets/Editor`.
- **Asset pack unused:** `House/PackProps` and `ExitDoorModel` are empty, walls/floor are still greybox cubes
  with `GB_*` materials; the 13 models and textures in `HauntedAssets` are not referenced by the scene.
- **Missing audio links:** `GameAudio.footstep` is null (no footstep sound) and the Enemy `AudioSource` has no
  clip (no hum), although `hum.wav`/`footstep.wav` exist.
- **Stray leftovers:** root `Walls` (ProBuilder mesh) and root `Floor` duplicate the generated geometry;
  `TestFloor` is inactive; `Directional Light`/`TempLights` are disabled.
- **Page count is duplicated, not shared:** `PageSpawner.pagesToSpawn = 4` and `GameManager.totalPages = 4`
  are independent. Raising `totalPages` alone would make the game unwinnable (key never spawns).
- **No null guards:** `Interactor` writes `promptText.text` unconditionally, `GameManager` dereferences
  `hintText`/`pageText`, and `EnemyAI` assumes `player`/`GameManager.Instance` exist — any of these missing in
  a variant scene throws NullReferenceException.
- **Hidden state is absolute:** while hiding the enemy can neither see, hear nor catch the player, so lockers
  are a risk-free pause rather than a stealth mechanic.
- `SampleScene.unity` and `TutorialInfo` are unused dead weight in the project.
